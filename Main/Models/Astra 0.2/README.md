# ASTRA 0.2: Basic Conversation

## Goal

ASTRA 0.2 focuses on natural assistant conversation: greetings, small talk,
casual reactions, preferences, everyday topics, simple explanations, and
conversational follow-ups.

The training mix may include elementary science and other simple everyday
questions. It should not drift into broad trivia, specialist knowledge, or
long-form instruction-following.

## Dataset

The target is **5,000+ quality-filtered conversation examples**.

- `dataset.txt` is the training source.
- The original 531 curated seed examples remain untouched by the importer.
- `fetch_and_filter.py` imports the training split from Hugging Face's
  **Everyday Conversations for Smol LLMs** dataset.
- The source contains 2,260 synthetic multi-turn conversations generated by
  Llama 3.1 70B Instruct and is distributed under the **Apache-2.0 License**.
- The importer reads the training split only, verifies its expected row count,
  and records a SHA-256 snapshot digest in `import_manifest.json`.
- Filters reject unsafe content, personal contact details, URLs, and assistant
  responses that claim human personal experiences or relationships.
- Imports are deduplicated against the existing dataset and tagged with source
  attribution.
- These are heuristic filters, not a guarantee that every retained example is
  perfect. Inspect the dry-run samples before importing.

Prefer:
- Greetings and goodbyes.
- Check-ins and small talk.
- Casual reactions and acknowledgements.
- Everyday preferences, hobbies, and plans.
- Simple everyday questions and elementary science.
- Short, natural follow-up replies.

ASTRA's assistant responses must not invent a human biography, personal
history, family, possessions, or offline experiences.

## Fetch and filter public data

Start with a dry run:

```bash
python3 fetch_and_filter.py --dry-run
```

If the samples and counts look good, import with:

```bash
python3 fetch_and_filter.py
```

Useful options:

```bash
python3 fetch_and_filter.py --dry-run --sample-count 30
python3 fetch_and_filter.py --max-add 1000
```

The importer uses Python's standard library and the Hugging Face dataset
viewer API. It does not install packages, call Ollama, or train the model.

Source:
- [Everyday Conversations for Smol LLMs](https://huggingface.co/datasets/HuggingFaceTB/everyday-conversations-llama3.1-2k)
- [Apache-2.0 license](https://www.apache.org/licenses/LICENSE-2.0)

## Prepare

Run the full preparation pipeline with one command:

```bash
python3 prepare_dataset.py
```

This removes only legacy unreviewed candidate blocks, rebuilds the tokenizer,
audits the corpus, and runs correctness checks. Verified imports and the
original curated examples are preserved. It does not train ASTRA.

## Generate and review new examples

Use the local Ollama model to draft a small batch when additional examples are
useful:

```bash
python3 conversation_workbench.py
```

The workbench generates candidates for optional manual review. The public
dataset importer does not require approving each pair one by one.

## Train

```bash
python3 train.py
```

Do not train until the dataset is large and its audit samples are acceptable.

## Generate

```bash
python3 generate.py "Hey! How's it going?"
```
