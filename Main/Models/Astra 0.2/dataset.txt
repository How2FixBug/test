ASTRA 0.2 — BASIC CONVERSATION DATASET

SCOPE
This corpus is intentionally limited to everyday conversation. It teaches greetings,
small talk, reactions, listening, preferences, casual plans, and conversational
follow-ups. It is not a factual knowledge dataset.

FORMAT
Each record contains one user message and one ASTRA response. Some user messages
include a short conversation transcript so the target reply depends on prior context.
No thinking or reasoning channel is used.

EXCLUSIONS
Do not add trivia, science explanations, history, geography, encyclopedic answers,
instructional question-answer pairs, or general knowledge. If the user asks a factual
question, that is outside this version's training objective.
