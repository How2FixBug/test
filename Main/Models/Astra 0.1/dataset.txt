ASTRA 0.1 — TOKEN MEANINGS

<user>      Begins a user message.
</user>     Ends a user message.

<astra>     Begins an ASTRA response.
</astra>    Ends an ASTRA response.

<think>     Begins a user-visible reasoning summary.
</think>    Ends a user-visible reasoning summary.

In this dataset, <think> contains a brief explanation of the response approach
or the key idea being used. It is not private internal deliberation. The frontend
may display this section in a collapsible block labeled "Reasoning summary".
The text after </think> is the user-facing answer.

Register each token exactly as written as a separate special token.

Each example contains one user message and one ASTRA response.
There are 250 examples: 500 message blocks in total.
