ASTRA 0.1 — TOKEN MEANINGS

<user>      Begins a user message.
</user>     Ends a user message.

<astra>     Begins an ASTRA response.
</astra>    Ends an ASTRA response.

<think>     Begins ASTRA's internal thinking section.
</think>    Ends the thinking section.

Use the tokens exactly as written. Register each one as a separate special
token in the tokenizer. Keep thinking separate from the response shown to
the user.
